# Backlog: WAI Windows Port (win_search)

Документ содержит декомпозицию задач по развитию, оптимизации и стабилизации Windows-порта WAI.

---

## 🎯 Стратегические цели проекта
1. **Производительность:** Мгновенный отклик поиска (< 30 мс) на коллекциях от 10 000 до 100 000+ фрагментов.
2. **Локальность и приватность:** 100% локальная обработка данных (NVIDIA, AMD Vulkan, Intel, CPU-fallback), отсутствие телеметрии и сетевых зависимостей.
3. **Функциональная полнота:** Распознавание текста скриншотов (OCR), поддержка ключевых форматов Windows (WebP, HEIC), мультиязычность (полноценный русский язык).
4. **Надёжность поставки:** Автономный дистрибутив (Velopack, no-admin, per-user), автоматизированные тесты (`dotnet test`).

```mermaid
flowchart LR
    Q["Запрос пользователя"] --> S1["Stage 1: Локальный отбор\n(HNSW Vector + FTS5)"]
    S1 --> TopK["Top-50 кандидатов\n(< 25 мс)"]
    TopK --> Agent["Stage 2: ИИ-Агент / Реранкер\n(Локальная LLM / OpenAI API)"]
    Agent --> Check{"Проверка сути\nи смысла документа"}
    Check -->|Релевантен| Ranked["Переранжированный Top-10\n+ краткая выжимка ответа"]
    Check -->|Ложное совпадение| Drop["Отсеивание шума"]
    Ranked --> UI["Выдача пользователю"]
```
