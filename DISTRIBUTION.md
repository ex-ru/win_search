# Установка, распространение и аппаратная архитектура WAI Windows

В данном документе описано:
1. **Почему папка `dist/` отсутствует/пуста в Git** и как скачать актуальный дистрибутив на любое устройство.
2. **Универсальная архитектура аппаратного ускорения** (CPU, дискретные NVIDIA / AMD / Intel Arc, встроенная графика Intel Iris Xe/UHD и AMD Radeon APU).
3. **Как опубликовать и собрать релиз**.

---

## ❓ 1. Почему дистрибутивы не хранятся напрямую в Git (`dist/`)?

При клонировании или синхронизации репозитория (`git pull` / `git clone`) на другом ПК папка `dist/releases` отсутствует либо не содержит файлов `.exe` и `.zip`.

### Технические причины:
1. **Лимит GitHub на размер файла (100 МБ)**:
   - Размер автономного инсталлятора `WinSearch.WAI-win-Setup.exe` составляет **~291 МБ**, а портативного архива `WinSearch.WAI-win-Portable.zip` — **~284 МБ** (включают рантаймы Vulkan, llama.cpp, AVX-варианты CPU, OCR, PDFium и SQLite).
   - При попытке отправить файлы такого размера в обычный Git сервер GitHub немедленно отклоняет push (`File exceeds GitHub's file size limit of 100.00 MB`).
2. **Исключение в `.gitignore`**:
   - В `.gitignore` явно прописаны строки:
     ```gitignore
     dist/releases/*.zip
     dist/releases/*.nupkg
     dist/releases/*.exe
     ```
     Поэтому Git намеренно не отслеживает эти тяжелые бинарники в истории коммитов.
3. **Ограничения Git LFS**:
   - Бесплатный тариф GitHub предоставляет всего 1 ГБ хранилища и 1 ГБ пропускной способности LFS в месяц. Три скачивания файла по 300 МБ полностью блокируют весь репозиторий до конца месяца.

## 🚀 2. Как скачать и установить готовый дистрибутив на другом ПК

### Вариант А: Одной командой PowerShell (Автоматически)
На целевом компьютере откройте PowerShell и выполните:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\download-release.ps1
```
*(Скрипт автоматически опрашивает GitHub Releases API, находит свежую версию, скачивает `WinSearch.WAI-win-Setup.exe` в `dist\releases\` и сверяет контрольную сумму SHA256).*

Для скачивания портативной версии:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\download-release.ps1 -Portable
```

### Вариант Б: Прямое скачивание из браузера
Зайдите на официальную страницу релизов репозитория:
👉 **[GitHub Releases: ex-ru/win_search](https://github.com/ex-ru/win_search/releases)**
1. Скачайте `WinSearch.WAI-win-Setup.exe`.
2. Запустите файл двойным кликом — приложение установится в безадминском режиме за несколько секунд, добавит ярлыки в меню «Пуск» и трей Windows.

### Вариант В: Перенос на USB-накопителе
Вы можете скопировать `dist\releases\WinSearch.WAI-win-Setup.exe` или `WinSearch.WAI-win-Portable.zip` на флешку или по локальной сети.

## ⚡ 3. Архитектура универсального аппаратного ускорения

Приложение спроектировано по принципу **«Один универсальный офлайн-установщик (All-in-One) с автоопределением и ручным выбором»**. 
Вам **не нужно докачивать внешние пакеты из интернета** — всё необходимое уже встроено в дистрибутив.

### Матрица поддерживаемого оборудования:
| Оборудование | Бэкенд | Примеры поддерживаемых устройств | Особенности |
|---|---|---|---|
| **Дискретные NVIDIA** | **CUDA / Vulkan** | GeForce GTX 10xx/16xx, RTX 20xx/30xx/40xx/50xx, Quadro | Максимальная скорость благодаря тензорным ядрам |
| **Дискретные AMD** | **Vulkan** | Radeon RX 5000/6000/7000 (например, RX 7900 GRE), RX 500/Vega | Нативная поддержка Vulkan 1.3 в драйверах AMD |
| **Дискретные Intel** | **Vulkan** | Intel Arc A310, A380, A580, A750, A770, Battlemage | Аппаратные XMX матричные ядра через Vulkan |
| **Встроенная графика Intel** | **Vulkan** | Intel Iris Xe, UHD Graphics 630/730/770, Core Ultra | Энергоэффективная работа на ноутбуках без перегрева |
| **Встроенная графика AMD** | **Vulkan** | Radeon 680M / 780M / 890M, Ryzen 3000–8000 APU | Высокая скорость инференса на современных APU |
| **Любой процессор (CPU)** | **CPU (AVX/AVX2/AVX512)** | Любые Intel Core / Xeon, AMD Ryzen / EPYC | 14 специализированных SIMD сборок (Haswell, Zen4, Alder Lake и др.) |

### Интеллектуальное автоопределение и Graceful Fallback:
1. **DXGI Детектор оборудования (`HardwareDetector`)**:
   - При старте приложение за доли миллисекунды опрашивает аппаратную подсистему через Windows DXGI (`dxgi.dll`, компонент ОС).
   - Классифицирует устройства: **дискретные GPU** (выделенная видеопамять > 1 ГБ) и **встроенные GPU**.
2. **Приоритет автоопределения (`Auto`)**:
   - Если в системе есть дискретная видеокарта (AMD / NVIDIA / Intel Arc) → вычисления направляются на неё.
   - Если дискретной карты нет, но есть интегрированная графика (Intel Iris Xe, AMD APU) → вычисления идут на встроенную графику.
   - Если видеокарта не поддерживает вычисления или вы работаете на виртуальной машине → активируется процессорный режим CPU.
3. **Безопасный откат (Graceful Fallback)**:
   - Если при загрузке модели в видеопамять произошел сбой (нехватка VRAM, сбой видеодрайвера TDR) — движок `wai-embed` **не падает с ошибкой**, а автоматически и бесшовно переключается на CPU.

### Ручное управление в окне Настроек:
В окне настроек WAI добавлена секция **«Аппаратное ускорение (CPU / GPU для эмбеддингов)»**:
- **Выпадающий список**:
  - `Автоопределение (Рекомендуется)` — отображает выбранный девайс, например: `Авто: AMD Radeon RX 7900 GRE (Дискретная)`.
  - `Дискретный GPU (GPU ext)` — принудительно использовать мощную дискретную карту.
  - `Встроенная графика (GPU int)` — использовать встроенное видеоядро (актуально для ноутбуков для экономии батареи).
  - `Только процессор (CPU only)` — отключить использование GPU для максимальной стабильности.
- **Информационный статус**:
  Показывает реальные характеристики ПК: модель видеокарты, объём доступной видеопамяти VRAM, количество ядер процессора.
- Изменения применяются мгновенно по нажатию кнопки **«Применить»** или **«Сохранить»**.

## 🛠 4. Сборка и публикация нового релиза

### Сборка установщика:
```powershell
powershell -ExecutionPolicy Bypass -File .\port\WAI-5c5c1f3ae2b4346353e34704b4783956d1ae8c4f\windows\scripts\build-package.ps1 -Version "1.0.7"
```
Скрипт автоматически:
1. Компилирует WPF-приложение, CLI и фоновый эмбеддер.
2. Комплектует нативные библиотеки (`vulkan`, `cpu SIMD`, `sqlite`, `pdfium`, `ffmpeg`).
3. Генерирует установщик Velopack `WinSearch.WAI-win-Setup.exe` и архив `WinSearch.WAI-win-Portable.zip`.
4. Считает контрольные суммы `SHA256SUMS.txt` и обновляет `releases.win.json`.

### Публикация в GitHub Releases:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish-release.ps1 -Version "1.0.7"
```
Скрипт загружает готовые файлы в GitHub Releases через GitHub CLI (`gh`) либо через GitHub API по токену, делая их доступными для всех остальных устройств.
