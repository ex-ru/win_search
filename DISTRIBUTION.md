# Установка и распространение DigUp Windows

В данном документе описано, где находятся дистрибутивы приложения и как установить DigUp на любое другое устройство с Windows.

---

## 📦 Где находятся дистрибутивы в репозитории

Готовые бинарные дистрибутивы собраны и расположены в каталоге:
```
dist/releases/
```

### Доступные пакеты:
| Файл | Назначение | Описание |
|---|---|---|
| **`WinSearch.DigUp-win-Setup.exe`** | **Установщик (Рекомендуется)** | Автономный безадминский установщик (Velopack). Устанавливает приложение в `%LocalAppData%\DigUp`, создает ярлыки в меню «Пуск» и на рабочем столе, настраивает автозапуск и фоновые обновления. |
| **`WinSearch.DigUp-win-Portable.zip`** | **Портативная версия** | Автономный ZIP-архив. Не требует установки: распакуйте в любую папку и запустите `DigUpApp.exe`. |
| **`releases.win.json`** | **Манифест обновлений** | Файл метаданных Velopack для проверки и скачивания обновлений. |
| **`SHA256SUMS.txt`** | **Контрольные суммы** | Хеши SHA256 для проверки целостности всех файлов дистрибутива. |

## 🚀 Способы установки на другое устройство

### Способ 1: Установка через клонирование репозитория (Git LFS)

Файлы установщика и портативного архива имеют размер около 300 МБ (содержат нативный Vulkan/GGML рантайм, llama.cpp, SQLite и движок OCR). Для их отслеживания в репозитории используется **Git LFS** (`.gitattributes`).

1. Убедитесь, что на целевом устройстве установлен Git и Git LFS:
   ```powershell
   git lfs install
   ```
2. Склонируйте репозиторий:
   ```powershell
   git clone https://github.com/ex-ru/win_search.git
   cd win_search
   git lfs pull
   ```
3. Запустите установщик:
   ```powershell
   .\dist\releases\WinSearch.DigUp-win-Setup.exe
   ```

---

### Способ 2: Скачивание из GitHub Releases

Если на другом устройстве нет Git, вы можете просто скачать готовый установщик или архив со страницы релизов GitHub:
👉 **[GitHub Releases: ex-ru/win_search](https://github.com/ex-ru/win_search/releases)**

1. Скачайте `WinSearch.DigUp-win-Setup.exe`.
2. Запустите его двойным кликом. Установка займет несколько секунд без запросов прав администратора.
3. Приложение сразу готово к работе:
   - В трее появится иконка поиска.
   - Горячая клавиша по умолчанию: `Ctrl+Alt+Space`.

---

### Способ 3: Перенос на флешке / сетевом диске

Вы можете просто скопировать файл `dist/releases/WinSearch.DigUp-win-Setup.exe` (или архив `WinSearch.DigUp-win-Portable.zip`) на USB-накопитель или сетевую папку и запустить на любом ПК под управлением Windows 10 или Windows 11 (x64).

## 🛠 Сборка нового релиза

Для пересборки дистрибутива из исходных кодов:
```powershell
powershell -ExecutionPolicy Bypass -File .\port\DigUp-5c5c1f3ae2b4346353e34704b4783956d1ae8c4f\windows\scripts\build-package.ps1 -Version "1.0.4"
```

Скрипт автоматически:
1. Выполняет `dotnet publish` для приложения и консольной утилиты.
2. Копирует необходимые нативные библиотеки (`pdfium.dll`, `ggml`, `llama`, `sqlite3`).
3. Упаковывает релиз через `vpk pack` (Velopack) в `dist/releases/`.
4. Генерирует `SHA256SUMS.txt` и `releases.win.json`.
