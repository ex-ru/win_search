# Стабилизация WAI перед выпуском

Выпуск 1.2.0, 15 октября 2026. Ветка: `codex/wai-production`.

## Требования и доказательства готовности

- [x] 1. Транзакция удерживает блокировку до commit/rollback, вложенность использует savepoint; вставка и получение ID атомарны. Поиск открывает собственный WAL-reader. Регрессии: SearchReliabilityTests.
- [x] 2. Один цикл индексации с объединением запросов; reset, смена модели и Dispose отменяют и дожидаются его остановки. Размерность и fingerprint принадлежат индексу. Регрессии: EngineLifecycleTests, MultiModelTests.
- [x] 3. Scope и типы ограничивают кандидатов до limit; снимок области поиска, пустая область, регистр Windows и старые векторные снимки проверяются в SearchReliabilityTests.
- [x] 4. Новое редактирование отменяет предыдущий запрос; результат проверяется по поколению. Worker имеет тайм-ауты, отмена завершает дерево процесса; сохранены Windows Job Objects. Регрессии: SearchWorkflowTests, SearchWindowTests, WorkerClientTests, JobObjectTests.
- [x] 5. Watcher объединяет события и передает пути локальной сверке; rename учитывает оба пути. Полная сверка остается для первого запуска и восстановления после переполнения. Недоступные поддеревья не удаляются из индекса. Регрессии: WatcherTests, IncrementalSyncTests.
- [x] 6. Русские регулярные словоформы, ё/е и ограниченные чередования гласных без префиксного расширения; точные реквизиты сохраняются. Добавлены проверки альтернативного code-индекса и маленьких семантических коллекций. Расширенный корпус: testbed-production.json.
- [x] 7. Повторное использование буферов, пакетное чтение метаданных, ограниченные параллельные разделы точного SIMD-сканирования. Замеры 10k/100k/1m приведены ниже. Экспериментальный HNSW не включен в основной поиск.
- [x] 8. Один проверяемый загрузчик с timeout/retry/resume, размером и SHA-256; ревизии четырех моделей закреплены. Готовность первого запуска требует успешного старта модели. Регрессии: DownloadReliabilityTests, OnboardingTests.
- [x] 9. .NET 10, полный пакет и независимые проверки реального lifecycle, падения, SQLITE_FULL, worker/native runtime и применения обновления. Окончательный пакет прошел BGE-M3 и default Gemma проверки; SHA загруженного Core сверяется с пакетом.
- [x] 10. Первый запуск в три шага, сокращенный основной экран настроек, Advanced для технических параметров. Двухэтапная выдача и понятные состояния ошибок/повтора; убраны недостоверные проценты уверенности и глобальные счетчики. Галерея и облачный reranker отложены.
- [x] 11. Активные Windows исходники, формы, package ID, скрипты и руководства используют WAI. Архивный upstream и исторические результаты не переписываются. Package ID: WinSearch.WAI.
- Поставка (12): [релиз WAI 1.2.0](https://github.com/ex-ru/win_search/releases/tag/v1.2.0), ветка `codex/wai-production`. Скрипт публикации закрепляет SHA исходников, загружает полный набор артефактов в черновик и проверяет размеры и SHA-256 на стороне GitHub до публикации. Пропущен отдельный сравнительный benchmark всех моделей; он требует явного запуска и локальных моделей и не считается успешным замером. SHA-256 загруженного Core совпадает с пакетом.

## Воспроизведение

```powershell
dotnet test .\port\WAI-5c5c1f3ae2b4346353e34704b4783956d1ae8c4f\windows\WAI.Windows.sln -c Release
.\port\WAI-5c5c1f3ae2b4346353e34704b4783956d1ae8c4f\windows\scripts\build-package.ps1 -Version 1.2.0 -Full
.\scripts\check-release.ps1 -PackageDir .\dist\staging -ModelsDir .\models -Native -ReportDir .\results\release-final
.\scripts\check-release.ps1 -PackageDir .\dist\staging -ModelsDir .\models -Model gemma2 -SkipEvaluation -Native -ReportDir .\results\release-default-model
.\scripts\check-update-apply.ps1 -PackageDir .\dist\staging -TargetReleaseDir .\dist\releases -ModelsDir .\models -ReportDir .\results\update-apply-final
dotnet run --project .\checks\WAI.Performance -c Release -- --counts 10000,100000 --million --repetitions 12 --report .\results\stabilization-performance.json
```

Модели и native-библиотеки должны быть подготовлены локально; release-проверки не скачивают зависимости. Недостающая обязательная зависимость вызывает ошибку. Все изменяемые пользовательские данные в проверках изолированы во временных каталогах. Harness сверяет SHA-256 реально загруженного WAI.Core.dll с проверяемым пакетом.

## Практические ограничения

- После открытия репозитория релиз и его метаданные доступны анонимно. Публичный канал не был доступен во время исходной проверки 1.2.0; актуальное состояние и новые незакрытые задачи приведены в [проверке публикации](PUBLICATION_REVIEW.md).
- Это локальная проверка CPU, не матрица видеокарт и драйверов. Интерактивная установка и перезапуск GUI после обновления не проверялись автоматизацией.
- Обновление проверяется на временной portable-установке: baseline содержит текущие бинарные файлы с меньшей версией пакета. Это реальное применение Update.exe с проверкой сохранности данных, но не миграция исторических бинарных версий.
- При новом package ID установите новый WAI installer. Сохраненные данные WAI остаются в %LocalAppData%\WAI; автоматического upgrade между разными package ID не обещаем.
- Установщик не подписан сертификатом. Встроенные вызовы PDF/OCR могут закончить одну нативную операцию перед обработкой отмены.
- Русская морфология не использует полный словарь исключений. При одном семантическом фрагменте нет относительной шкалы уверенности: потребуется совпадение слов.
- Синтетический корпус не гарантирует качество на произвольных пользовательских данных. Отсутствующие темы проверяются на ложные лексические совпадения; смысловая выдача для них остается диагностикой.
