# Проверка готовности WAI к публикации — 2026-10-15

Исходники прошли повторную техническую проверку. **Перед широким распространением остаются незакрытые задачи поставки:** комплект лицензий/соответствующих исходников сторонних компонентов и проверка установленного GUI на чистой Windows. Добавление новых пользовательских функций не требуется.

## Что исправлено

- Изменения энергосбережения из `main` (`2f501ea`) совмещены со стабилизацией в PR #1. Сохранены сериализация индексации, отмена/таймауты воркеров, incremental watcher и настройки backend. Фоновые воркеры получают ограничение потоков и EcoQoS; поисковые запросы сохраняют отдельный режим.
- Исправлена фильтрация событий watcher: исчезнувшая или переименованная папка с суффиксом `.tmp` должна пройти сверку индекса. Тест проверяет сохранение обоих путей при переименовании.
- Тест `TerminateAll` изолирован от параллельных тестов воркеров. Проверка EcoQoS учитывает отличие Windows 10 от Windows 11.
- CI дополнен self-contained publish для WPF, CLI и worker. У workflow минимальные права чтения и отмена устаревших запусков. Сборка и применение полного installer в CI пока не выполняются.
- README и инструкции установки описывают публичный репозиторий. Добавлены карта каталогов, CONTRIBUTING, SECURITY, пояснение результатов и инвентаризация сторонних компонентов.
- Генерируемые release manifests и сырые TRX исключены из отслеживания Git; локальные файлы сохранены. Их исторические версии остаются в Git, переписывания истории не было. Убраны ненужные правила Git LFS для игнорируемых пакетов.
- Builder Guide больше не обещает сборку полного CPU/Vulkan-пакета из чистого clone существующим экспериментальным CUDA-скриптом.

## Что ещё нужно закрыть

1. **PUB-02, P0 — лицензии и происхождение бинарных файлов.** В 1.2.0 копируются только лицензии WAI и LLVM OpenMP. Проверенный FFmpeg сообщает `--enable-gpl --enable-version3`; точный источник PDFium и полный набор matching notices не зафиксированы. Нужно восстановить происхождение и соответствующие исходники/уведомления, включить материалы в основной пакет и отдельный FFmpeg-архив. Подробности — [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), требования проекта FFmpeg — [официальная страница](https://ffmpeg.org/legal.html). Работа приложения и SHA-256 не закрывают этот пробел поставки.
2. **PUB-03 — чистая Windows и установленный GUI.** Нужна проверка Windows 10/11 без SDK: установка обычным пользователем, первый запуск/модель, поиск, выход/повторный запуск и upgrade с сохранением данных. На текущей машине есть инструменты разработчика; она не заменяет чистую VM. GPU-матрица также не проверена.
3. **PUB-04 — воспроизводимая подготовка runtime.** Managed source checks работают из checkout, но полный package ожидает локальные `run-vulkan/` и `tools/`. Закреплённый процесс получения CPU/Vulkan, FFmpeg и notices нужен для сопровождения и повторяемого выпуска.

Установщик пока не подписан; предупреждение издателя указано в инструкции. Это отдельное улучшение доверия к поставке. Текущие опубликованные assets/tag 1.2.0 не заменялись и не содержат новых изменений энергосбережения. Следующий binary release должен получить новую версию после закрытия выпускных задач.

## Приоритеты бэклога

Оставлены в работе над выпуском: надёжность, состав пакета, проверяемая установка и понятные инструкции. IDE-интеграция, открытие PDF на точной странице, seek медиа, автокалибровка CPU/GPU и уточнение ETA перенесены после выпуска. HNSW остаётся прототипом вне основного поиска; галерея и облачный reranker по-прежнему отложены.
