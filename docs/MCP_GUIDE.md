# Руководство по интеграции WAI с ИИ-агентами (Model Context Protocol / MCP)

WAI 1.2.0 может предоставлять MCP-клиенту инструменты поиска, чтения содержимого и просмотра метаданных проиндексированных файлов. Интерфейс MCP не предоставляет инструментов записи или изменения файлов. Он не изолирует остальные возможности самого ИИ-клиента или агента.

## Доступные инструменты

| Инструмент | Назначение |
|---|---|
| search_documents | Гибридный семантический и полнотекстовый поиск по локальному индексу. Поддерживает ограничение количества и тип результата. |
| read_document_content | Чтение доступного содержимого документа или указанного фрагмента. |
| get_document_info | Получение индексированных метаданных выбранного файла. |
| get_index_status | Сводка о локальном индексе и состоянии модели. |

Пользовательские файлы и индекс остаются на компьютере. Подключенный агент получает сведения и фрагменты, возвращенные вызванными инструментами; учитывайте это при настройке доступа агента.

## Нативное подключение через wai mcp

В настройках MCP-клиента укажите исполняемый файл wai.exe, установленный вместе с WAI, и аргумент mcp. Путь установки зависит от системы и версии Velopack; возьмите его из свойств ярлыка WAI или выберите exe в каталоге установки. Не используйте путь к данным в %LOCALAPPDATA%\WAI как путь к программе.

Пример JSON для Claude Desktop, Cursor, VS Code или другого MCP-клиента:

~~~json
{
  "mcpServers": {
    "wai": {
      "command": "<full path to installed wai.exe>",
      "args": ["mcp"]
    }
  }
}
~~~

Замените значение command на фактический путь к установленному wai.exe. Поле command не обязано раскрывать переменные окружения Windows, поэтому строка %LOCALAPPDATA% внутри него может не работать.

В Docker Agent укажите тот же исполняемый файл и аргумент в MCP toolset:

~~~yaml
agents:
  assistant:
    model: your-model
    toolsets:
      - type: mcp
        command: "<full path to installed wai.exe>"
        args: ["mcp"]
~~~

## Проверка связи

Запустите wai.exe с аргументом mcp из настроенного клиента. Для ручной проверки MCP-клиентом выполните initialize и tools/list, используя штатный транспорт stdio. Ожидаемая версия сервера для пакета WAI 1.2.0:

~~~json
{"jsonrpc":"2.0","id":1,"result":{"protocolVersion":"2024-11-05","capabilities":{"tools":{}},"serverInfo":{"name":"wai-mcp","version":"1.2.0"}}}
~~~

Если команда не запускается, проверьте путь к исполняемому файлу, перезапустите MCP-клиент после изменения конфигурации и убедитесь, что WAI уже запустили для создания индекса.

## Необязательный Python-клиент

В репозитории есть Python-обертка tools/mcp/wai_mcp.py для проектов, которым нужен FastMCP-совместимый интерфейс. Это необязательно для нативного wai mcp-сервера:

~~~powershell
uv run tools/mcp/wai_mcp.py
~~~

Пакет использует идентификатор WinSearch.WAI. Данные WAI под %LOCALAPPDATA%\WAI сохраняются при обновлении; автоматический переход с установок, у которых другой package ID, не гарантируется.
