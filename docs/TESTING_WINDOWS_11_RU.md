# Проверка WAI 1.2.1 на Windows 11

Для группы тестирования: установите пакет из [релиза 1.2.1](https://github.com/ex-ru/win_search/releases/tag/v1.2.1). Отдельная установка .NET или Python не нужна. Установщик пока не подписан; Windows может показать предупреждение издателя.

1. Запустите Setup от обычного пользователя. Убедитесь, что установка и запуск не требуют прав администратора.
2. Пройдите первый запуск: выберите небольшую папку с тестовыми файлами, дождитесь загрузки модели и индексации. При отмене загрузки должен оставаться понятный способ повторить её.
3. Откройте поиск через Ctrl+Space. Найдите файл по точным словам, затем по описанию. Проверьте фильтр типа и открытие результата.
4. Проверьте предпросмотр картинки и PDF через Пробел. Если используете видео/аудио, добавьте короткие файлы и дождитесь обработки.
5. Создайте, измените, переименуйте и удалите тестовый файл. После спокойного интервала мониторинга (около 15 секунд) и обработки результаты должны обновиться.
6. Закройте приложение через меню трея, запустите заново. Папки и результаты должны сохраниться. Обычное закрытие окна поиска скрывает его; это не выход из приложения.
7. Если есть совместимая видеокарта, проверьте стандартный режим и CPU в расширенных настройках. Сообщите модель GPU и версию драйвера при проблемах.
8. Если тестируете обновление с WAI 1.2.0, сохраните настройку и тестовый индекс перед обновлением. После применения 1.2.1 проверьте версию, настройки и поиск старых файлов.

Сообщайте о проблемах через [Issues](https://github.com/ex-ru/win_search/issues): версия WAI/Windows, CPU/GPU, шаги, ожидаемый и фактический результат. Используйте синтетические файлы; уберите личные пути, содержимое документов и секреты из скриншотов и логов. Особенно полезны случаи зависания, потери настроек, оставшихся дочерних процессов после выхода и неработающего предпросмотра.
