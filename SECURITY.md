# Reporting vulnerabilities

Security fixes target the latest Windows release. Older releases are not maintained separately.

Use [GitHub private vulnerability reporting](https://github.com/ex-ru/win_search/security/advisories/new) when available. If private reporting is unavailable, open an issue asking for a private contact channel without including exploit details, private documents, index databases or credentials. No response-time guarantee is currently offered.

WAI processes local files, model downloads and native decoding libraries. Reports should identify the affected version, component and a minimal synthetic reproduction. Do not upload your actual search index or model tokens.
