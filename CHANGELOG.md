# Changelog: WAI Windows Port (win_search)

Все заметные изменения проекта фиксируются в этом документе.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.2.0] - 2026-10-15

### Fixed
- Транзакции SQLite изолированы между потоками; вставки и получение идентификатора записи атомарны. Поиск использует собственный WAL-снимок.
- Папки и типы файлов ограничивают кандидатов до применения лимита. Учитываются регистр Windows, пустая область поиска и изменение индекса во время запроса.
- Индексация выполняется одним циклом; отмена, сброс, переключение модели и завершение приложения согласованы с его остановкой. Изменения файлов обрабатываются с debounce и локальной сверкой подкаталогов.
- Устаревшие запросы отменяются, запуск и ответы worker ограничены тайм-аутами. Неправильная размерность и устаревшие векторы не используются в поиске.
- Исправлен недостижимый статистический порог смыслового поиска при 2–5 фрагментах; добавлены проверки отрицательных совпадений и русских словоформ.
- Проверки выпуска требуют реальных зависимостей и исполняют готовые бинарные файлы; пропущенный benchmark не считается успешным замером.

### Changed
- Повторное использование буферов и пакетное чтение метаданных ускоряют точный векторный поиск; основной конвейер не использует экспериментальный ANN.
- Первый запуск состоит из трех шагов. Основные настройки сокращены, технические параметры перенесены в Advanced. Лексические результаты появляются перед смысловыми; добавлены понятные состояния ошибок и повторной попытки.
- Установщик и feed используют package ID WinSearch.WAI.
- Сборка по умолчанию создает полный пакет со встроенным FFmpeg; в пакет входят CPU и Vulkan backends, CUDA в него не включена.
- Глобальный хоткей по умолчанию — Ctrl+Space.
- Репозиторий фиксирует .NET SDK 10.0.402 в global.json.
- URL, ревизии и контрольные суммы моделей закреплены; загрузчик проверяет ожидаемый размер и SHA-256.
- Данные WAI в %LocalAppData%\WAI сохраняются. Автоматический upgrade между установками с разными package ID не гарантируется.

### Примечание к историческим результатам

Метрики ниже описывают отдельные запуски на небольших тестовых наборах и конкретном оборудовании. Они не являются гарантией качества поиска, поддержки всех форматов или времени ответа на пользовательских коллекциях.

## [1.1.0] - 2026-10-13

### Added & Changed
- **Архитектура множественных моделей эмбеддингов и селектор моделей (Model Selector):**
  - В настройках приложения добавлен выбор активной модели машинного обучения (`ComboEmbeddingModel`):
    * **BGE-M3 (BAAI, 568M, 1024 dim)** — мировой лидер в русскоязычном и мультиязычном поиске, длинный контекст до 8192 токенов.
    * **EmbeddingGemma 2 (Google, 2.6B, 768 dim)** — универсальная мультимодальная модель с нативной поддержкой аудио и видео через mmproj.
    * **Nomic Embed v1.5 (Nomic, 137M, 768 dim)** — компактная модель; исторические оценки скорости и памяти относятся к конкретному тестовому прогону и не являются гарантией.
    * **Perplexity Embed v2 (0.6B Fast CPU INT8, 1024 dim)**.
  - Поддержка динамической размерности векторов: `Vectors.Dimension`, `VectorStore.cs`, `HnswIndex.cs`, `Searcher.cs` автоматически подстраиваются под размерность активной модели (768 или 1024 dim) с сохранением метаданных в SQLite.
- **Изменения индексации для моделей с разными возможностями:** реализован fallback-конвейер для моделей без media projector. Фактическое покрытие зависит от выбранной модели, экстрактора, формата и содержимого файла; универсальная обработка всех типов не обещается.
- **Облегченный инсталлятор и On-Demand загрузчик компонентов:**
  - Размер инсталлятора `WinSearch.WAI-win-Setup.exe` сокращен более чем в 2 раза (со ~291 МБ до ~125 МБ) за счет вынесения тяжелых утилит FFmpeg (455 МБ без сжатия) в отдельный пакет `ffmpeg-tools-win-x64.zip`.
  - Разработан `ComponentDownloader.cs` с поддержкой докачки, контроля целостности и автоматического размещения компонентов в `%LocalAppData%\WAI\`.
  - В релизе 1.1.0 `build-package.ps1` поддерживал варианты `-Slim` и `-Full`; с версии 1.2.0 полный пакет собирается по умолчанию.
  - `scripts/download-release.ps1` расширен опциями выбора пакета: `-Slim`, `-Full`, `-Portable`, `-IncludeTools`.
- **Тестовый стенд и сравнительный бенчмарк моделей (`scripts/benchmark-models.ps1`):**
  - Подготовлен тестовый стенд на базе `testbed/` и валидационного набора `testbed-russian-eval.json`.
  - Реализован запуск автоматизированных тестов производительности CPU и точности Top-1 ранжирования (`ModelBenchmarkTests.cs`).
  - Сгенерирован детализированный отчет `results/benchmark-models-report.md`.
- **Надежность и обработка ошибок:**
  - `WAI.Embed` (Program.cs): добавлена явная UTF-8 кодировка консольных потоков и корректная обработка некорректного JSON без блокировок.
  - Для версии 1.1.0 в журнале сборки указано 85+ пройденных тестов; это исторический результат того запуска, а не текущая проверка checkout.

Добавлена кнопка фиксации `📌` (Pin), позволяющая закрепить документ на экране и продолжать поиск других файлов, а также возможность свернуть или скрыть главное окно поиска, оставив предпросмотр открытым на рабочем столе.
- **Плавающий десктопный виджет поиска (Point 3):** Полноэкранный блокирующий оверлей и блюр заменены на компактный десктопный виджет Windows. Добавлены кнопки управления: свернуть (`—`), закрыть/скрыть в трей (`✕`), перетаскивание за заголовок мышью и маскот `🐾 WAI`.
- **Стилизованные плашки клавиш (Point 4):** В нижней панели добавлены бейджи клавиш `[Пробел]` (предпросмотр), `[↵ Enter]` (открыть), `[Esc]` (закрыть).
- **Горячая клавиша по умолчанию (Point 5):** Дефолтная комбинация быстрого вызова изменена на `Ctrl+Space` с автоматической миграцией старых настроек.
- **Частичная очистка векторного индекса (Point 6):** В настройках добавлена кнопка «Очистить векторы выбранной папки», выполняющая точечный сброс эмбеддингов для выбранной директории без необходимости полной переиндексации всех источников.
- **Кастомный темный скроллбар (Point 7):** Разработан единый стилизованный ScrollBar в темной теме приложения (узкий полупрозрачный трек, скругленный ползунок с акцентом при наведении), заменяющий системный белый Win32 скролл.
- **Удаление настроек размытия (Point 8):** Настройки размытия Acrylic и затемнения удалены из интерфейса и модели конфигурации в пользу оконного режима виджета.
- **Локализация и выбор языка (Point 9):** Добавлена настройка языка интерфейса (Русский RU по умолчанию / English EN) и статический класс `Loc` для системных строк и уведомлений.
- **Фоновые обновления через GitHub Releases (Point 10):** В `UpdateService.cs` подключен нативный источник `Velopack.Sources.GithubSource` для бесшовного фонового обновления приложения из репозитория `ex-ru/win_search`.
- **Кнопка «С помощью…» (Point 11):** Добавлена кнопка вызова системного диалога выбора программы (`OpenAs_RunDLL`) и учет переменных окружения `VISUAL` / `EDITOR`.
- **Информационное предупреждение о первичной индексации (Point 12):** В настройках добавлен понятный баннер о том, что первичная индексация может занять время, но приложение можно закрывать — при следующем запуске обработка автоматически продолжится.
- **Релиз 1.0.5 и инсталлятор (Point 13):** Версия поднята до 1.0.5, что обеспечивает корректное in-place обновление установщика Velopack без ложных запросов на восстановление.

## [0.1.0-alpha] - 2026-10-12

### Baseline (PR #18 Windows Port)
- Историческая исходная версия Windows-порта использовала C#/.NET 9 и WPF; текущая ветка собирается с .NET SDK 10.0.402.
- Процесс-воркер `wai-embed.exe` на базе llama.cpp (b11461) с протоколом JSON-lines для EmbeddingGemma 2 (Q8_0, 768-dim).
- Полнотекстовый и векторный индекс в SQLite (`IndexStore`, WAL, FTS5).
- Консольная утилита `wai.exe` с командами `estimate`, `index`, `search`, `status`.
- Базовая версия Windows-порта использовала глобальный хоткей Ctrl+Alt+Space; текущая комбинация по умолчанию — Ctrl+Space.
